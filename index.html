業務流程 (SRS v0.7)

1. 模組一：資料匯入與匯出

資料匯入：支援批次 (200+) PDF / Excel 檔案匯入。
匯入作業需在「背景執行」。
上傳時需供使用者自行新增 (輸入) 年分欄位。
系統將對該年度的既有資料執行解析後，再進行「全刪全覆蓋」。
[待處理] PDF 讀取與擷取所用的套件選擇。

錯誤處理 - 全有或全無：若批次中有任一 PDF 檔案「毀損、無法讀取、或為純圖片」，則整批作業終止，不得寫入資料庫，並回報錯誤檔案。

Excel 匯出匯回：使用者可「依所選年度」匯出所有資料。
使用者可在匯出檔上修改後重新匯入（系統需具備依唯一 ID 進行資料更新的能力）。

狀態欄位：系統需追蹤並顯示每年度資料的處理狀態，狀態應包含：「pdf 轉資料庫」、「pdf解析失敗」、「完成上傳」、「相似度比對分析」、「完成分析」。

2. 模組二：相似度比對分析

批次分析：使用者可手動觸發「最新年度」vs.「所有歷史資料」的比對。
比對欄位： 內容摘要、效益性、應用性、革新性。
[待處理] 各欄位的比對權重及演算法，將於後續階段定義。

儲存結果：系統需將比對結果（分數 1.0 - 0.0）存入資料庫。
[待處理] 儲存結果的詳細「資料庫儲存格式」尚待提供。

3. 模組三：報告產出與檢視

線上報告檢視：系統需提供一新頁面，供匯出 (模組二) 產生的所有文章比對結果。

最終報告產出介面： 系統需提供一個功能頁面，包含三個輸入項：
1. 比對值 (門檻): 使用者輸入 (例如：0.8)。
2. 資料儲存路徑 (基底): 使用者輸入 (例如：D://Report_Files/)。
3. 總表上傳: 使用者上傳業務已部分填寫的 Excel 總表。

回填規則 (Hyperlink)： 依據 總表.xlsx 樣板，系統需針對總表中的每一筆資料，自動找出比對分數 Top 3 的結果，並回填總共 3 個欄位（類似案件1、類似案件2、類似案件3）。
關鍵邏輯： 這 3 個儲存格均需為「超連結 (Hyperlink)」。
超連結顯示文字： 應為 Top 3 案件的「案件名稱」。
超連結位址： 應為 Top 3 案件的「檔案路徑」，且此路徑需遵循 (B) 規則。

路徑規則 (B)： 系統需將「原始路徑」的根目錄，替換為使用者輸入的「基底路徑」。

範例：
原始路徑：C:/System_Data/Archive/2024/file_A.pdf
輸入基底：D://Report_Files/
產出路徑 (超連結位址)： D://Report_Files/2024/file_A.pdf
[待處理] 超連結顯示文字規則待PM詢問。

產出： 系統將這份填寫完整的 Excel 報告，提供給使用者下載。
